# 开发路线与边界

当前执行计划：[v0.1.0 开发、发布与节点验收](V0.1.0_PLAN.md)。后续按该计划推进，每到节点主动提醒用户检查；下文保留既有技术边界。

## A：侧栏原型（第一道门禁）

实现 MCP App UI 资源和 global 入口，使用维护中的 MCP SDK；先返回合成数据。

验收：插件正常安装、发现入口、在侧栏显示/固定、点击打开、读取数据、重启后恢复、卸载不残留配置。只通过协议测试不能声称宿主 UI 验收通过。不修改 Codex 安装包或隐藏开关。

## B：只读清单

扫描明确的本机用户/系统目录。2026-10-21 用户确认首版保留本机范围，不增加项目目录扫描。插件 manifest 和安装记录为归属证据；插件缓存只作为候选，不视作安装事实。

区分逻辑技能与安装实例。路径、来源、版本、内容指纹共同用于识别，不能仅凭名称合并。状态包括确认启用、确认停用、缓存候选、未知、缺失。

验收：中文路径、符号链接、同名不同内容、旧缓存及嵌套示例均有有意义测试；与人工抽样盘点一致。

## C：使用记录

按日志实际结构设计解析器；增量读取，保留来源定位而不保存全文。显式调用、宿主激活、读取推断和自报分开；管理器扫描不得计入使用。

验收：重复导入幂等、恢复/分叉重放去重、分段读取不累加、损坏日志可恢复、无法归属事件保留未解析状态。展示覆盖时间，禁止伪造历史数据。

## D：整理和管理

先实现内容指纹查重与同名冲突；语义相近只是候选。用户可备注低频保留或用途不同。管理写操作先预览影响，再备份与执行；系统和插件附带内容默认只读。

验收：配置失败可恢复、并发修改检测、路径范围验证、归档恢复、操作记录，不覆盖其他设置。

## E：交付

验证 Windows 安装、升级、重启与卸载，维护支持矩阵。无后台服务为默认，不启动外部模型服务。UI 在窄侧面板和全屏可用，支持键盘与清晰错误状态。

## 技术决策

MCP 服务 / 清单扫描 / 日志解析 / 统计规则 / UI 分层。存储优先 SQLite，具体运行时在 A 阶段根据 SDK 和本机环境验证后确定。任何偏离均记录理由。

使用索引原型暂采用有版本的 JSON 快照、排他锁和临时文件替换，复用 Node 20，不引入原生 SQLite 安装依赖；快照限制 64 MiB，每次读取限制 32 MiB。它只适合当前受限单机原型，达到容量边界时需迁移到 SQLite，不能静默丢弃历史。并发导入拒绝，异常退出残留锁需检查后处理。

视觉方向：白色背景 #FFFFFF、浅灰底 #F3F5F7、正文 #20252B、蓝色操作 #245EAA、绿色确认 #26714B、橙色待核 #925B12；中文系统无衬线字体。列表与详情为主，不用大面积指标卡或装饰图。数字必须带时间与统计口径。
