## 目标与范围

v0.1.0 定义为其他用户可以独立安装、使用、升级的首个公开可用版本。先支持 Windows；优先交付可靠安装和数据保留，不以增加图表、恢复全部旧页面或跨平台支持作为本版本前提。不改变本地数据边界，不引入云端日志上传或外部模型服务。

当前基线：v0.0.1-alpha.1 已发布；双语 UI 与英文 README 已合并。此前构建通过，47 项测试通过、1 项跳过；这只是基线证据，不能代替后续改动验证或真实宿主验收。

## 分发路线

1. GitHub Releases：保留源码和可运行发布包入口。
2. 自建 GitHub marketplace：完整产品优先分发途径。补齐配置并实际验证后，才宣传市场添加命令。
3. skills.sh：发布配套 SKILL.md，不能把安装 Skill 等同于安装完整 MCP 服务。按官方 FAQ，真实安装经 CLI 匿名安装统计进入榜单；不刷安装量，不保证即时收录。
4. OpenAI 公共插件目录：并行确认资格，但不把获批作为 v0.1.0 发布前提。当前本地 stdio MCP 需要合作伙伴准入和组织允许名单；不要改成云端服务来绕过限制。

公开目录准备：发布者身份、插件 ZIP、图标/说明、产品/支持/隐私/条款 URL、五个正向与三个负向用例、演示视频、版本说明。提交前重核规则；外部身份验证、条款确认与代表联系由用户提供所需决定，不自行代办或发送消息。
