# v0.1.0 正式发布范围与检查

2026-10-23 用户取消 alpha/beta 阶段，要求统一版本和文档、检查后合入 main、发布正式 GitHub Release，并清理已合并分支。许可证明确选择 Apache-2.0。Agent 代验收授权继续有效。

## 本版范围

- 正式版本 0.1.0、标签 v0.1.0，非 prerelease。
- 采用源码 ZIP → 显式安装依赖/构建 → MCP 注册。源码、锁文件、构建脚本和文档入 Git；运行 bundle、node_modules、缓存和用户记录不入 Git。
- 一键远程 marketplace、npm 发布、公共目录上架不纳入本版。本地市场构建器仍是开发工具。
- 最新原生侧栏自动化、未测平台及升级边界见 KNOWN_LIMITATIONS.md，不把未验证项标为通过。

## 发布检查

1. package/lock、MCP 服务、UI 和生成 manifest 版本一致；许可证及第三方文本随产物保留。
2. 最终版运行相关回归和隔离安装/持久化检查，实际结果写入 VALIDATION.md。
3. 源码发布包排除私有配置、依赖目录和生成 bundle；记录 source commit、校验值及安装步骤。
4. 审查 PR 后合入 main，仅删除确认已合并的来源分支；未合并实验保留并说明。
5. 正式 Release 指向核实的 main commit，发布后核对标签、状态、附件。

此前 M1–M6 预发布安排由本计划取代；历史证据保留在 [VALIDATION.md](VALIDATION.md)，不代表全部宿主行为通过。
